# Brand audit

Each conclusion is marked **EXISTING BRAND ELEMENT** (observed in the Instagram presence) or **NEW WEBSITE INTERPRETATION** (a website decision derived from it).

## What exists

| Element | Observation | Tag |
|---|---|---|
| Logo / wordmark | None. The profile picture is a property photograph (a contemporary house with timber garage doors and a sea view). | EXISTING BRAND ELEMENT (absence) |
| Name | "Luxury Homes Of SA" followed by the South African flag emoji | EXISTING BRAND ELEMENT |
| Grid | Pure photography. No graphic templates, text tiles or branded frames on LHOSA-authored posts. Text overlays (price stickers, agents on camera) appear **only** on collaborator reels. | EXISTING BRAND ELEMENT |
| Photo grading | Saturated HDR estate photography: cerulean skies, aqua pools, white render with charcoal aluminium, face-brick, timber, stone, lawns. Exteriors and aerials lead; dusk shots recur. | EXISTING BRAND ELEMENT (agency photography, curated) |
| Composition rhythm | Carousel of up to 20 frames: exterior hero, then living, kitchen, bedrooms, bathrooms, outdoor, aerial | EXISTING BRAND ELEMENT |
| Caption voice | Factual, spec-led, understated one-line headline ("Sophisticated luxury with stunning views"), then a ✔️ checklist, sizes, levies/rates, beds/baths/garages. No hype in LHOSA-authored captions; hype ("WOULD YOU BUY IT?") is collaborator voice. | EXISTING BRAND ELEMENT |
| Price presentation | ZAR first, then USD, GBP and EUR equivalents on every LHOSA listing. This signals an international buyer audience. | EXISTING BRAND ELEMENT |
| Location emphasis | Instagram location tag plus estate/suburb hashtags on every post; national scope (6 provinces) | EXISTING BRAND ELEMENT |
| Colour | No brand colour. The feed's colour is entirely photographic. | EXISTING BRAND ELEMENT (absence) |
| Typography | None (Instagram default) | EXISTING BRAND ELEMENT (absence) |
| South African identity | Flag emoji, "SA" in the name, estates and suburbs as the vocabulary, braai/boma/borehole/load-shedding solar features in the text | EXISTING BRAND ELEMENT |

## Website interpretation

| Decision | Rationale | Tag |
|---|---|---|
| "Particulars" concept: architectural sales particulars as an editorial publication | Mirrors the spec-sheet caption discipline; ownership rather than stays | NEW WEBSITE INTERPRETATION |
| Typographic wordmark "Luxury Homes of [SA]", with SA in a charcoal mono tile | There is no logo to preserve; the tile echoes the flag-suffix habit without using a flag | NEW WEBSITE INTERPRETATION |
| Ground `#f1f2ef` (render plaster), ink `#1b2023` (anodised aluminium) | Taken from the dominant materials in the photography; cool, so it doesn't fight blue skies | NEW WEBSITE INTERPRETATION |
| Single accent `#a1421f` face-brick | Face-brick is a ubiquitous South African building material and the complement of the feed's blues, so it sits beside the photography without competing. Avoids the black/gold, beige/brass, navy and estate-agent-green defaults. | NEW WEBSITE INTERPRETATION |
| Archivo variable (expanded widths for display) + IBM Plex Mono for figures | Architectural signage feel; mono carries the spec-sheet precision of the captions; completely distinct from Fraunces + Jost | NEW WEBSITE INTERPRETATION |
| Multi-currency line under price, dated "as published" | Preserves an existing brand habit honestly: the historical conversions are shown with their date and marked indicative | EXISTING ELEMENT, NEW PRESENTATION |
| Square geometry (radius 0) | Architectural drawings, not holiday softness; also differentiates from Exclusive Cape Town's pill buttons | NEW WEBSITE INTERPRETATION |
| Features as a hairline-bulleted two-column list | Mirrors the ✔️ checklist without emoji | NEW WEBSITE INTERPRETATION |

## Clichés deliberately avoided

Protea or Big Five motifs, flag graphics, "Mzansi" wordplay, sunset gradients, gold foil, script fonts, "dream home" copy.
